math.wasm round trip

With Content-Encoding: add-key, send 3: the service worker encodes it as 103 with math.wasm add(). The .NET server decodes it to 3 with the same math.wasm, adds 2, encodes 5 as 105, and the service worker decodes it back to 5.

Without it, 3 and 5 travel as-is. Compare both in the Network tab.
